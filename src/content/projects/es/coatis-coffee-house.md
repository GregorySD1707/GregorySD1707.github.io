- Resolví los **riesgos de desabastecimiento de inventario** usando Python al desarrollar un motor automatizado de pronóstico que combina la clasificación ABC y el suavizado exponencial de Holt-Winters (statsmodels) para **predecir la autonomía del inventario** y **activar alertas de reposición en tiempo real**.

- Construí colaborativamente un dashboard interactivo de Inteligencia de Negocios en Streamlit que integra **analítica de ventas**, **reglas de venta cruzada** mediante el algoritmo Apriori (mlxtend) y **segmentación RFM de clientes** con clustering K-Means (scikit-learn).

- Migré la base de datos local de PostgreSQL a una base de datos cloud serverless en Neon y desplegué la plataforma en Streamlit Cloud, implementando una gestión de entornos cifrada con SSL.
