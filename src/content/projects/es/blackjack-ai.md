- Aumenté la **precisión de detección en un 60% (del 55% al 88%)** mediante la implementación de un flujo de visión por computadora con el modelo de aprendizaje profundo YOLOv8, el framework PyTorch y el procesamiento de arreglos de NumPy, alcanzando métricas competitivas de detección en tiempo real.

- **Reduje el tiempo de inferencia en un 70% (de 10 s a 3 s)** mediante la optimización de la GPU con CUDA y precisión FP16, el preprocesamiento adaptativo con OpenCV y la eliminación de duplicados usando el algoritmo IoU.

- **Logré una mejora del 40% en la detección de bordes** aplicando extracción adaptativa de ROI con padding inteligente mediante técnicas de visión por computadora y arquitecturas de redes neuronales de TensorFlow/Keras.

- Diseñé una API RESTful asíncrona con el framework FastAPI, procesando imágenes mediante endpoints validados con Pydantic y logrando la integración completa entre el frontend de JavaScript y el backend de Python.
