- Solved **inventory stockout risks** using Python by engineering an automated forecasting engine combining ABC classification and Holt-Winters Exponential Smoothing (statsmodels) to **predict stock autonomy** and **trigger real-time reorder alerts**.

- Built collaboratively an interactive Streamlit Business Intelligence dashboard integrating **sales analytics**, **cross-selling rules** via Apriori algorithm (mlxtend), and **RFM customer segmentation** with K-Means clustering (scikit-learn).

- Migrated local PostgreSQL database to Neon serverless cloud DB and deployed the platform on Streamlit Cloud, implementing SSL encrypted environment management.
